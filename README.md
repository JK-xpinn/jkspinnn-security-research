# Cybersecurity Research Portfolio

Security research, application testing, and threat investigation.

I document hands-on cybersecurity work with an emphasis on web and API security, vulnerability assessment, threat intelligence, and security operations.

## Focus Areas

- **Web application security:** authentication, authorization, input validation, session management, and common web attack classes.
- **API security:** endpoint testing, access-control checks, request manipulation, and evidence-based reporting.
- **Threat intelligence:** IP and infrastructure research, indicator analysis, and investigation workflows.
- **Security operations:** log analysis, event correlation, suspicious-activity investigation, and incident timelines.
- **Network analysis:** service discovery and traffic inspection.

## How I Approach Security Work

1. Define the scope and permitted testing boundaries.
2. Identify relevant attack surfaces and security controls.
3. Test hypotheses using repeatable requests and observable evidence.
4. Record impact and limitations without overstating results.
5. Recommend practical remediation and retesting.
